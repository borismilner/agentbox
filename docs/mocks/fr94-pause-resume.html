FR94 - take the keyboard back mid-run, without ending the run

A run is binary today, so the only way to get the mouse back is to fight the agent for it. This adds a third state. Drive the stage below: pause with the hotkey, watch what the agent sees on the right, then settle the three open questions at the bottom. Nothing here is built yet.

The stage

Super + Esc - or click the strip. Focus the page and press Esc to fire it here.

What the paused sign looks like

Presence is the whole signal in FR74: on screen means an agent is driving, gone means the desktop is yours. Pause breaks that binary, so the paused form has to read as the opposite pole while still being present - and it has to stay out of the way, because you paused precisely to use that screen. Pick one; the stage uses it live.

The three open questions

Where this lands if it is built. internal/daemon/control.go gains the third state and the gate that MethodDrive waits on (today it calls drv.Drive unguarded, daemon.go:762). internal/hotkey already grabs a global combo and rebinds it live, so the key costs a second hotkey.Open and a config knob, not a new mechanism. frontend/src/surfaces/Control.svelte gains the paused form. The pause never travels over MCP in the un-pause direction: no tool resumes a run, or the pause is a suggestion.
